# Archived poster artifacts

`poster_preview.png` and `poster_preview.pdf` preserve the historical final
export from the original working folder. They are presentation artifacts, not
the canonical statement of results: their wording about a statistically
significant paired Jigsaw difference predates the overlap check for repeated
splits. Read the current [result and limitation statements](../../README.md#results-and-scope)
and [`outputs/claim6_paired.csv`](../../outputs/claim6_paired.csv) instead.

`poster.html` is a revised, editable source: it replaces the unsupported
significance language with a descriptive comparison and uses the bundled
`images/` files. `poster_embed.html` is the original self-contained HTML export.
